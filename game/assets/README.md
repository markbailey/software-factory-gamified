# Software Factory sprites

Original hand-authored SVG artwork (generated by `../tools/gen_sprites.py`, so the set stays consistent; edit the script and re-run rather than editing files by hand). 55 files.

## Grid and conventions

- Square grid, `CELL = 64` px, top-down view, light from the top left.
- Outline `#16181C`, about 2 px. Floor base colour `#292B30`.
- Every file has explicit `width`/`height`/`viewBox`, no text, fonts, filters, masks, clip paths, `<style>` or external references. Only shapes, paths, group transforms, and linear/radial gradients (plus `stroke-dasharray` in `overlay_failed.svg`, `splitter.svg`, `merger.svg` and `fill-rule="evenodd"` in `icon_settings.svg`).
- Anchor: top-left of the image = top-left of the footprint. No padding to compensate for (machine bodies start 4 px in; scrap bin lugs reach 1 px from the edge).

| Folder | Size | Footprint |
|---|---|---|
| `machines/` | 128x128 | 2x2 cells |
| `belts/` | 64x64 | 1 cell |
| `floor/` | 64x64 | 1 cell, tiles seamlessly |
| `crates/` | 32x32 | drawn centred on a belt cell |
| `ui/` | 32x32 | icons |

- Flow is drawn west to east. A port is a dark slot on the body edge spanning y = 26..102 with an accent arrow at y = 36 and y = 92, so a belt can dock on either the upper or the lower cell of that side.
- Splitter/merger branch channels sit on the cell-row centres (y = 32 and y = 96); their single channel is on the side's centre (y = 64).
- Status lamp: neutral grey disc, centre **(110, 14)**, radius 4.5 (housing radius 7.5), on every machine and station. Draw a filled circle in the state colour there, and/or use the overlays.

## belts/ (64x64)

Band is 36 px wide and centred (14..50), rails 5 px on both sides (9..14, 50..55), chevrons point in the direction of travel.

- `belt_straight_<dir>.svg`: travel direction `e`, `w`, `n`, `s`.
- `belt_corner_<from>_<to>.svg`: items **enter through the `<from>` edge** of the tile and **leave through the `<to>` edge**. Example: `belt_corner_w_n` connects the west and north edges, moving toward north. All 8: `w_n w_s e_n e_s n_e n_w s_e s_w`.
- `belt_end_<dir>.svg`: end cap (roller and yellow stop) on the `<dir>` side; travel toward `<dir>`.

Picking a tile from the previous and next cell: `from` = side the previous cell is on, `to` = side the next cell is on. If they are opposite, use `belt_straight_<to>`.

Clockwise loop: `s_e` (top-left), `w_s` (top-right), `n_w` (bottom-right), `e_n` (bottom-left). Counter-clockwise: `e_s`, `s_w`, `w_n`, `n_e`.

White icons are `#E6E9EF`, so they can be tinted with `modulate`. The node rings in `icon_merge`/`icon_pr` are filled with the floor colour `#292B30`.

## Using them in Godot 4

Copy this folder to `res://assets/`. Godot imports each SVG as a `Texture2D` (rasterised at import; raise "SVG > Scale" in the Import dock for HiDPI).

```gdscript
const CELL := 64
const TEX_CODER: Texture2D = preload("res://assets/machines/coder.svg")
const TEX_RUNNING: Texture2D = preload("res://assets/machines/overlay_running.svg")
const TEX_CRATE: Texture2D = preload("res://assets/crates/crate.svg")
const LAMP := Vector2(110, 14)

func _draw() -> void:
    # machine: top-left cell (cx, cy), 2x2 footprint
    var origin := Vector2(cx, cy) * CELL
    draw_texture_rect(TEX_CODER, Rect2(origin, Vector2(128, 128)), false)
    # state: lamp dot and frame overlay
    draw_circle(origin + LAMP, 4.5, Color("4C8DF2"))
    draw_texture_rect(TEX_RUNNING, Rect2(origin, Vector2(128, 128)), false)
    # crate centred on a belt cell (bx, by), plus travel offset along the belt
    var centre := (Vector2(bx, by) + Vector2(0.5, 0.5)) * CELL
    draw_texture_rect(TEX_CRATE, Rect2(centre - Vector2(16, 16), Vector2(32, 32)), false)
```

- Overlays already carry their state colour; pass a `modulate` colour with lower alpha as the last argument of `draw_texture_rect` to pulse them.
- Belts need no rotation: pick the file by name, e.g. `load("res://assets/belts/belt_corner_%s_%s.svg" % [from, to])`.
- Draw order: floor, belts, crates, machines, overlays.
