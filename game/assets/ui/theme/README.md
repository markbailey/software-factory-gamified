# Software Factory GUI theme

A decluttered, minimal look for the game's GUI: flat dark surfaces a shade lighter than the floor, one accent colour, 1 px lines, small radii, no bevels, gradients or shadows. State colours (blue, green, amber, red) are used only to show state.

- `factory_theme.tres`: Godot 4 `Theme` (text, format 3, no uids). Only `StyleBoxFlat` / `StyleBoxEmpty` / `StyleBoxLine`, 20 small SVG icons and one `SystemFont` (monospace). No font files, no textures for panels.
- `icons/`: 16x16 control glyphs (toggles are 28x16). Same constraints as the sprites: explicit `width`/`height`/`viewBox`, shapes and paths only.
- Generated by `tools/gen_theme.py` (theme) and `tools/gen_sprites.py` (icons). Edit the tokens at the top of `gen_theme.py` and re-run instead of editing the `.tres` by hand; the HTML mock reads the same tokens.
- Mock-ups: `art/gui_mockup.html` (all screens), `gui_mockup.png` / `gui_mockup_720.png` (running, 1920x1080 and 1280x720), `gui_mockup_build.png`, `gui_mockup_intake.png`, `gui_mockup_bin.png`, `gui_states.png` (every variation and state).

## Applying it

Copy `assets/` to `res://assets/` as before, then either:

```ini
; project.godot
[gui]
theme/custom="res://assets/ui/theme/factory_theme.tres"
```

or, since the UI is built in code under one `CanvasLayer` (`main.gd` `_build_ui`), put a full-rect `Control` under it, set `theme` on it and parent every panel to it:

```gdscript
var root := Control.new()
root.set_anchors_and_offsets_preset(Control.PRESET_FULL_RECT)
root.mouse_filter = Control.MOUSE_FILTER_IGNORE
root.theme = preload("res://assets/ui/theme/factory_theme.tres")
ui.add_child(root)          # then root.add_child(top) and so on
```

The project setting is simpler and also themes tooltips and `OptionButton` pop-ups, which are separate windows.

Pick a variation per node:

```gdscript
approve_button.theme_type_variation = &"ButtonApprove"
bottom_panel.theme_type_variation = &"PanelDockBottom"
```

Then delete the local overrides so the theme shows through: the `_panel_style()` / `StyleBoxFlat.new()` blocks (`build_panel.gd`, `inspector.gd`, `intake_view.gd`, `bin_view.gd`), `banner_style` in `main.gd`, the `add_theme_font_size_override("font_size", 17/18/15)` calls on titles, and the `modulate = Color(0.75, ...)` on hints and counters (use `LabelMuted`).

## Tokens

| Token | Value | Used for |
|---|---|---|
| floor | `#292B30` | the factory floor (reference) |
| surface | `#30333A` at 97% | panels, docks, top bar, toasts |
| field | `#24262B` | wells: inputs, lists, log |
| raised | `#3A3E47` | default button |
| hover / pressed | `#454A55` / `#2B2E35` | button states |
| border / divider | `#41454E` / `#3A3D45` | 1 px lines / separators |
| text / muted / disabled | `#E6E9EF` / `#9AA1AD` / `#646A75` | |
| accent | `#8CBFFF` (hover `#A8CFFF`, pressed `#74ACF0`), text on it `#16181C` | focus ring, selection (18% tint), primary button, caret |
| running / pass / amber / fail | `#4C8DF2` / `#5ABF66` / `#F2B84C` / `#E5484D` | state only; red text on dark is `#FF8A8E` |

- Spacing scale: 4, 8, 12, 16. Box and grid separation 8. Dock padding 16 x 12, floating panels 12, buttons 12 x 5 (30 px tall), fields 10 x 5.
- Radius: 4 on controls and toasts, 6 on floating panels (cards, banner, pop-ups), 0 on docks.
- Font sizes: body 14, heading 16, muted 13, mono 13, keycap 11, tooltip 13. Godot's default font is kept.
- Font note (recommendation only, nothing added): the default project font is Open Sans SemiBold, which is a little heavy for this look. Inter or IBM Plex Sans at regular weight would be calmer; set it as the theme's `default_font` if you add one. The mock is rendered with Inter because Open Sans is not installed where it was built, so text in the game will be slightly heavier and wider than in the PNGs.
- Monospace: `LabelMono`, `LogText` and `RichTextLabel`'s `mono_font` use a `SystemFont` (JetBrains Mono, Cascadia Mono, Consolas, SF Mono, Menlo, DejaVu Sans Mono, Liberation Mono, monospace). On a platform with none of them Godot falls back to the default font.

## Type variations

| Variation | Base | Use |
|---|---|---|
| `ButtonPrimary` | Button | the one main action in a view: Add, Save |

| `ButtonApprove` | Button | Approve at a gate (solid green) |

| `ButtonTile` | Button | build palette tiles; with `toggle_mode` the pressed tile (the machine being placed) gets the accent outline |
| `PanelDock` | PanelContainer | panel docked to the left edge (line on its right side) |
| `PanelDockRight` | PanelContainer | panel docked to the right edge |
| `PanelDockBottom` | PanelContainer | panel docked to the bottom edge |
| `PanelBar` | PanelContainer | the top bar |
| `PanelToast` | PanelContainer | neutral / info toast (grey bar on the left) |
| `PanelToastSuccess`, `PanelToastWarn`, `PanelToastError` | PanelContainer | toast with a green / amber / red bar |
| `PanelBanner` | PanelContainer | the "Claude is unavailable" strip |
| `PanelTooltip` | PanelContainer | the crate hover tip (same box as the built-in `TooltipPanel`) |
| `LabelHeading` | Label | panel titles |
| `LabelMuted` | Label | hints, descriptions, counters, timestamps |
| `LabelMono` | Label | single lines of output |
| `LabelKey` | Label | keycap hint: `Esc`, `Enter`, `F` |
| `LogText` | RichTextLabel | the crate log and a machine's latest output (mono, in a well) |

Plain `Panel`, `PanelContainer` and `PopupPanel` are the floating card (6 px radius, 1 px border). Also themed without a variation: `Button`, `OptionButton`, `MenuButton`, `CheckBox` (square and radio), `CheckButton` (toggle), `LineEdit`, `TextEdit`, `SpinBox` (arrows; its field is a `LineEdit`), `RichTextLabel`, `ItemList`, `Tree`, `PopupMenu`, `TabBar`, `TabContainer`, `ScrollContainer`, `VScrollBar` / `HScrollBar` (6 px grabber, no track), `ProgressBar` (fill is running blue; set `modulate` or a stylebox override for other states), `HSeparator` / `VSeparator`, `TooltipPanel` / `TooltipLabel`, and the box / grid container separations.

Buttons take 32 px icons from `assets/ui/` at 16 px (`icon_max_width = 16` is in the theme; the palette tiles use 28). Icons follow the text colour, so white icons dim on ghost buttons and go dark on primary ones.

## Layout

The canvas is 1152x648 logical pixels (Godot's default viewport; the project stretches it with `canvas_items` / `expand`), so at 1920x1080 everything is drawn 1.67x larger and at 1280x720 1.11x. All sizes below are logical pixels, and everything is anchored to an edge so a different viewport size only adds floor.

| Region | Anchor | Size | Notes |
|---|---|---|---|
| Top bar | top, full width | 44 high (`TOP_BAR` stays) | spec field (min 340, max 480), Add, spacer, counters, connection, Build |
| Left dock | left edge, under the bar, to the bottom | 360 wide | one at a time: machine status, intake list, bin / dock list, build settings. Scrolls |
| Right dock | right edge, under the bar, to the bottom | 320 wide | build palette, build mode only |
| Bottom dock | bottom edge, from the left dock's right edge (or 0) to the right edge | 180 high, 218 with the gate row | crate log; shown while a crate is selected |
| Banner | under the bar, 8 px gap, from the left dock + 12 to the right edge - 12 | 46 high | one line, clipped; details in the tooltip |
| Toasts | top right, 12 px in, under the bar (and under the banner when it shows) | 300 wide | at most 4, 8 px apart; in build mode shift left of the right dock as `_place_toasts` does |

Per screen:

- **Running** (`gui_mockup.png`): the status dock replaces the floating 400 px window. Order: title and close, description (muted), status line with a state dot and the time on the right, crate line, risk badge and reason, "Open crate's full log", separator, steps, waiting list, separator, facts and stats (muted). Leave out "Latest output" while that crate's log is open in the bottom dock; it is the same text twice.
- **Crate log**: header row = `Crate #id` (heading), title (clipped), risk badge + level and source (muted), Open PR (ghost), close. The gate row (note field, Approve, Send back / Reject, Scrap) sits under the header and only exists while the crate waits for approval. Retry goes in the same row for scrapped crates.
- **Build** (`gui_mockup_build.png`): palette in the right dock (title, line picker with New / Delete, separator, 2-column tiles, one muted hint, Cancel / Save pinned to the bottom). Settings in the left dock. Separators between groups replace the long stacked labels.
- **Reviewer auto-approve**: the mock shows a `CheckButton` "Auto-approve when the review looks good" with an indented `OptionButton` "and the risk is at most: Low / Low or medium" (icons `icon_risk_low` / `icon_risk_medium`). Off maps to `AUTO_APPROVE_LEVELS[0]` (`""`), on to the picked level; hide the picker and its hint when off. The existing single three-item `OptionButton` also works unchanged with the theme if you prefer not to touch the logic.
- **Intake** (`gui_mockup_intake.png`): section head = source icon, name, count (muted), "Check now" (ghost); one muted line for the last check. Each row has one text button at most: "Pull in" for an issue that is not in the factory. A row that is already a crate shows that in its status line, so its button becomes the `icon_log` ghost icon; the link is the `icon_open` ghost icon.
- **Scrap bin / dock** (`gui_mockup_bin.png`): row = id and title, reason in red (bin) or green (dock) plus source (muted), Retry, log icon.
- **Keys**: `Esc` keycap next to the close button of whatever Esc closes next (bin, intake, status, then the log); `Enter` inside the spec field.
- Not in the theme, because `factory_floor.gd` / `crate.gd` draw them: machine names, the amber waiting badge, the red bin count, progress bars, crate ids, selection rings. They already use the same palette.

## Validation

`python3 tools/gen_theme.py` checks the `.tres` it writes: balanced brackets and quotes, `load_steps`, every `SubResource` / `ExtResource` id defined and used, every icon path present, no duplicate theme items. It has not been loaded in Godot (not installed where this was built), so open it once in the editor; an item name the running Godot version does not know is ignored, not an error.
